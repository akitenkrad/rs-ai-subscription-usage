# 使いどころ

## 何のための道具か

Claude Code も Codex CLI も，セッションごとの JSONL ログをローカルに残します．1 行が 1 応答の利用量を持ち，Codex の場合はその時点でサーバが返した利用制限の消化率も含まれます．そしてこれらのログは刈られます — Claude Code は `~/.claude/projects` の transcript を約 30 日で削除し，Codex もいずれ `~/.codex/sessions` を片付けます．**刈られる前に取り出していなかったものは，二度と戻りません．**

`ai-subscription-usage` はこれらのログを走査して月次の集計に畳み，利用制限の観測値は追記のみの永続記録として貯めます．出力は Obsidian vault の中の素の JSON なので，vault 内のダッシュボードがサーバ無しでそのまま描画できます．

### 答えられること

- どのモデルが何トークン使ったか．日ごとに，メインの会話とサブエージェントを分けて．
- 今月の通信量は，公開されている API 価格に換算するといくらぶんか．
- 5 時間枠・週次枠の消化率は今どこか．そしてここ数週間どういう曲線を描いたか．
- 費用のうちサブエージェントの取り分はどれくらいか．

### あえて答えないこと

- **「AI に払っている合計はいくらか」** — Claude と Codex を足しません．別々のサブスクリプションで，別々の利用制限を持ちます．合算した数字には解釈が付きません．
- **「請求額はいくらか」** — 出てくる金額は **API 価格に換算した参考額**であって請求書ではありません．サブスクリプションは定額であり，これは「同じ通信を API で流していたらいくらだったか」です．価格表に無いモデルは `null` として出します．**`$0` にはしません．**
- **「トークン数から見て利用制限は何 % 埋まっているか」** — 消化率をトークン数から推定することはありません．正とするのは観測値だけです（Codex 自身の `rate_limits`，または Anthropic の利用制限 API）．観測が無ければ，`0%` とは書かず何も書きません．

## 典型的な使い方

### 日次で集計してダッシュボードへ流す

集計を 1 日 1 回，利用制限の取得を 1 時間に 1 回，launchd で回します（→ [運用](operations.ja.md)）．すると vault には常に，プロバイダごとの最新の `YYYY-MM.json` と，1 日 1 点に間引いた `_limits.json` が置かれます．画面を開くたびに読んでも軽い大きさに収まります．

### ログが刈られた後から履歴を復元する

state ファイルと利用制限の JSONL は**キャッシュではなく唯一の長期記録**です．transcript が消えた後もその集計が残っているのは `state.json` に畳み込まれていたからであり，過去の消化率が残っているのは `limits.jsonl` に追記されていたからです．どちらも `~/.local/share/ai-subscription-usage/` にあり，どちらもバックアップの対象です．→ [アーキテクチャ](architecture.ja.md#state-はキャッシュではなく記録そのもの)

### 書き込む前に走査結果を確かめる

`--dry-run` は走査と要約の表示だけを行い，state・月次 JSON・利用制限の記録のいずれにも触れません．新しい機械やバックアップから復元した環境で「何が出るのか」を安全に確かめる手段です．

### 上限に当たった週を後から調べる

`_limits.json` は画面のために 60 日ぶんの日次ピークだけを持ちますが，その裏の JSONL は全観測点を持ち，さらに `rate_limits` オブジェクトをログにあったまま丸ごと保持しています — CLI が型に写していない欄，たとえば「実際に上限に当たったか」を示す欄も含めて．元のログが刈られた後，その週がなぜ止まったのかを示す証拠は，たいていそこにしか残っていません．

## 前提と範囲

- macOS．Claude の利用制限の取得は `security` コマンドでログインキーチェーンから OAuth トークンを読み，定期実行は launchd で行います．
- 時刻は固定オフセット `+09:00`（JST）で日に畳みます．日の区切りは UTC ではなく JST の 0 時です．
- 両プロバイダのログは既定の場所（`~/.claude/projects`，`~/.codex/sessions`）から直接読みます．外部への通信は，`claude limits` が Anthropic の利用制限 API を 1 回叩く以外にありません．
